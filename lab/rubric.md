# Rubric

Scored 0–5 per criterion. Sections get added as we learn each topic. Each criterion should be
checkable by someone else, not a vibe.

## General (applies to every output)
- **Specificity** — could this only be about this product, or could you swap in a competitor's name?
- **Customer language** — does it sound like the buyer talks, or like a marketer writes?
- **Clear single idea** — one message, not three fighting each other.

## Hooks (draft from curriculum/01-hooks.md; refine in the lab)
- **Specific** — a number, a named situation or a concrete object, not an adjective.
- **About the viewer** — names them or their situation in the first line.
- **Opens a loop the piece closes** — a reason to see the next second, and it pays off.
- **Works muted** — movement in frame 1 and readable on-screen text.
- **Not swappable** — a competitor couldn't run the same line unchanged.
- **No banned openers** — "In this video…", "Hello and welcome…", "Have you ever wondered…", empty "huge/insane".
