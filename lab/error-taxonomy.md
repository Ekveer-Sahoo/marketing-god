# Error taxonomy

Short, reusable tags so the same mistake gets counted as the same mistake. Add tags as we discover
them; merge duplicates. Format: `tag` — definition — example.

## Seed tags
- `generic` — output would fit any competitor — "High-quality products you can trust"
- `feature-not-outcome` — talks about what it is, not what it does for the buyer
- `wrong-awareness` — message pitched at the wrong awareness level for the audience
- `weak-hook` — first line or first 3 seconds give no reason to stop scrolling
- `no-proof` — claim without mechanism, demo, number, or social proof
- `muddled` — more than one core message
- `ai-voice` — reads like AI or corporate copy, not a human
- `off-platform` — format or tone doesn't match the channel (TikTok vs LinkedIn vs Meta)
- `video-artifact` — generated video has visual defects that break believability
